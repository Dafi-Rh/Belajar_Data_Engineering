Catatan Error - Latihan 06

1. Slicing list

angka = [6, 7, 9, 2]

print(angka[1:2]) -> [7]
print(angka[1:3]) -> [7, 9]
print(angka[1:4]) -> [7, 9, 2]
print(angka[1:])  -> [7, 9, 2]
print(angka[:2])  -> [6, 7]


2. Slicing dengan step

print(angka[::3]) -> [6, 2]
print(angka[::2]) -> [6, 9]


3. Slicing dengan index negatif

print(angka[:-1]) -> [6, 7, 9]
print(angka[:-2]) -> [6, 7]


4. Slicing yang menghasilkan list kosong

print(angka[4:-2]) -> []
print(angka[4:1]) -> []

Catatan:
Default step adalah +1, jadi arahnya maju.


5. Membalik list

print(angka[::-1]) -> [2, 9, 7, 6]


6. Slicing mundur

print(angka[4:0:-1]) -> [2, 9, 7]

Catatan:
step -1 membuat slicing bergerak mundur.


7. Tuple

angka = (7, 1, 8, 5, 4, 9)

print(len(angka)) -> 6
print(angka[0]) -> 7
print(angka[1:4]) -> (1, 8, 5)


8. Mencoba mengubah isi tuple

angka[4] = 10

Error:
TypeError: 'tuple' object does not support item assignment

Catatan:
Tuple tidak bisa diubah setelah dibuat.


9. count()

print(angka.count(1)) -> 1


10. index()

print(angka.index(4)) -> 4


11. for pada tuple

for nilai in angka:
    print(nilai)

Hasil:
7
1
8
5
4
9
