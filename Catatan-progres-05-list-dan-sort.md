## Materi yang sudah dicoba

- Membuat dan mencetak list
- `for` pada list
- `len()`, `max()`, `min()`, dan `sum()`
- Menghitung total dengan loop
- Menghitung rata-rata
- `in` dan `not in`
- `if / else` untuk mengecek isi list
- `remove()`, `pop()`, dan `insert()`
- `sort()`
- `sort(reverse=True)`
- Memahami `TypeError`, `SyntaxError`, `NameError`, dan `IndexError`

## Contoh hasil

```python
angka = [3, 5, 0, 9, 7]

angka.sort()
print(angka)
# [0, 3, 5, 7, 9]

angka.sort(reverse=True)
print(angka)
# [9, 7, 5, 3, 0]
```
